# Evaluation plan

1. Preregister the decision-research question, criteria scales, information-age thresholds and weight ranges before collecting observations.
2. Compare tabletop workflows against a documented baseline using civilian coordination scenarios. Keep synthetic, simulation and observational records explicitly labeled.
3. Evaluate comprehension of uncertainty, identification of stale information, rationale completeness, task completion time and review disagreement. Establish participant consent and a suitable study protocol.
4. Test joint preference changes, criterion correlations, scale choices and omitted variables outside the current one-at-a-time sensitivity analysis.
5. Review related work before claiming differentiation. Weighted additive comparison, interval arithmetic, provenance and sensitivity are established methods; this prototype does not demonstrate revolutionary advances.
6. Conduct keyboard, screen-reader, mobile-layout and real-browser interaction checks, including import errors, local-storage restrictions and export behavior.
7. Validate observed performance independently. Do not translate synthetic scores into live operational control or deployment readiness.

Current evidence is software-level reproducibility and test fixtures. No human-subject study, field validation, external integration, performance superiority or DARPA partnership is established.
